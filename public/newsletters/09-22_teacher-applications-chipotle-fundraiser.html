Teacher Applications

 

Our classes take place in person on Saturdays, and teachers generally commit about 3-4 hours per week.

We’re looking for Columbia and Barnard students with coding experience in Python and HTML, CSS, and JavaScript to volunteer for one of the following classes:

  • Class 1: Introduction to CS in Python (10 am - 12:30 pm)
  • Class 2: Web Development in HTML, CSS, and JavaScript (1 - 3:30 pm)
  • Class 3: Data Structures and Algorithms (4 - 6:30 pm)

The application is open to students of all genders and class years.

Applications are due Sunday, September 27, at 11:59 p.m. ET.
